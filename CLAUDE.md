## Project Overview

Gotcha is a Chrome Extension (Manifest V3) that provides AI-powered explanations for text selected on any webpage. When a user selects up to 5 words, a popup appears with a simple explanation generated by OpenAI's GPT-4o-mini model. The UI and code comments are in Brazilian Portuguese.

## Development

This is a vanilla JavaScript Chrome extension with no build step, no package manager, and no external dependencies. To develop:

1. Open `chrome://extensions` in Chrome
2. Enable "Developer mode"
3. Click "Load unpacked" and select the project directory
4. After making changes, click the refresh button on the extension card

There are no test, lint, or build commands.

## Architecture

The extension has a flat structure with three core files:

- **manifest.json** — Extension config (MV3). Declares `activeTab` and `scripting` permissions. Registers `index.html` as the default popup.
- **content.js** — All runtime logic. Dynamically creates the popup DOM, listens for text selection (`mouseup`), calls the OpenAI API via `fetch`, and manages popup positioning/visibility. Uses `AbortController` to cancel in-flight requests when new text is selected.
- **index.html** / **style.css** — Popup markup and dark-themed styling. The popup is hidden by default and toggled via a `visible` CSS class with opacity/scale transitions.

### Data flow

```
Text selection (mouseup) → content.js validates (≤5 words)
  → explicar() calls OpenAI chat completions API
  → Response displayed in popup positioned near cursor
```

### API key management

The OpenAI API key is stored in `localStorage` under `gotcha_api_key` and configured via a prompt dialog triggered by the config button in the popup.
