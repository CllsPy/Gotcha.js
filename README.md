# Explanations

### manifest.json

- É um arquivo para definir as regras da extensão (e.g nome do projeto, qual versão dele) e o que o seu navegador vai mostrar quando você abrir a página.

### index.html

- mostra textos na tela (e.g Resposta)
- chama código que contém o llm e a personalização (cores, bordas)
